# 万能视频下载网站 - 方案设计（MVP）

## 1. 目标
输入视频链接，解析视频信息并下载，覆盖 YouTube / B 站 / Twitter 等主流平台。不含数据库、不含用户系统，作为独立学习项目，参考鱼皮 free-video-downloader 课程的实现思路但自己重写。

## 2. 技术选型
- 后端：Python + FastAPI + yt-dlp
- 前端：React + Vite + Tailwind CSS
- 视觉参考：cobalt.tools（极简黑白 + 等宽字体 + 大输入框）+ 自加营销区块（功能卡片 / 支持平台墙 / Pricing 占位）

## 3. 后端设计

### 3.1 模块划分
- `downloader.py`：yt-dlp 封装层，负责解析、下载、取直链
- `main.py`：FastAPI 路由层

### 3.2 接口
| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/health` | GET | 健康检查 |
| `/api/parse` | POST `{url}` | 解析视频信息 + 格式列表 |
| `/api/direct-url` | POST `{url, format_id}` | 获取直链，浏览器直接下载 |
| `/api/download` | POST `{url, format_id}` | 服务端代理下载后返回文件流 |

### 3.3 下载模式选择策略
- 优先尝试直链模式（`/api/direct-url`），不占服务器带宽
- 直链不可用或平台有防盗链限制时，回退到服务端代理模式（`/api/download`）
- 由前端捕获 direct-url 失败后自动切换到 download 模式

## 4. 前端设计
- 首屏：超大居中输入框 + 极简黑白配色 + 等宽字体，参考 cobalt.tools
- 解析结果区：缩略图 + 标题 + 时长 + 清晰度选择卡片
- 营销区（新增，cobalt 没有）：支持平台 icon 墙、功能亮点卡片、Pricing 占位卡（本期不接支付逻辑）
- 强调色：黑白为主 + 一个高饱和跳色，避免通用蓝紫渐变 SaaS 模板感
